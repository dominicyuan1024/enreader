# enreader 伊恩阅读

一款英文原著阅读器，便于阅读、翻译与记录生词  
✔epub 格式：暂不支持其他格式书籍文件  
✔书架：书籍导入与管理  
✔阅读：进度、目录、笔记  
✔生词本：可点选标记书中单词，自动加入生词本，自动记录单词所在句子   
✔翻译：离线字典 《牛津高阶英汉双解词典（第10版）》  
✔主题设置：字体大小、配色    
✔打卡分享：生词云图  
✔存储：使用 indexDB 存储数据，刷新页面不会丢失，但不同浏览器之间数据无法共享

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
